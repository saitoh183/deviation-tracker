Privacy Policy

Last updated: May 15, 2026

Summary

The tracker is designed as a local-first tool. It does not require an account and does not intentionally collect analytics, tracking identifiers, or personal information.

Data stored by the app

The web version stores your tracker data in your browser using localStorage. The desktop version stores your tracker data locally in a SQLite database on your machine.

This can include characters, deviation rows, variants, traits, materials, OCR settings, and app preferences.

Screenshot OCR / AI providers

If you enable OCR or screenshot analysis, the app sends the selected screenshot and prompt data to the provider you configure. That provider may process and retain data according to its own privacy policy.

If you choose a local provider such as Ollama/LM Studio/llama.cpp, processing can stay on your own machine or network, depending on your setup.

What is not collected by this app

  • No user accounts are created by the tracker.
  • No built-in analytics are collected by the tracker.
  • No tracker database is uploaded by default.
  • No API keys are intentionally transmitted anywhere except the provider endpoint you configure for OCR.

Exports and backups

If you export or share backup/config files, those files may contain your tracker data and configured lists. Treat exported files as your responsibility.

Third-party hosting

The web version may be served through GitHub Pages. GitHub may receive normal web server request data such as IP address, browser user agent, and requested URLs according to GitHub’s own policies.

Deleting data

In the web version, clear site data for the tracker domain or use the app’s clear/export options. In the desktop version, remove app data from the local application data folder or use the app’s data management options where available.

Contact

Issues and feedback can be submitted through the project repository: github.com/saitoh183/deviation-tracker.
